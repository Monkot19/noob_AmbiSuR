# selector_v3_spread：原生7K候选评分结果

本次传播候选在既定静态评价中取得了明确的正向信号，值得讨论下一轮30K重建实验；它尚不是最终mesh收益，也没有证明单独的传播公式带来了全部改善。候选来源、锚点门控和适用区域一起改变了，接受域明显缩小。

## 输入与实际执行

- 新capture：用户下载的 `analysis/static_candidate_capture_spread_native7k_v1/static_native7k_v1`，服务器固定8b1def920b2d4722e9ff238ed2116a477cd4846c、clean、RTX4090、退出0。17份NPZ全部用现有 `validate_record` 实际解码验证，manifest/计数一致。
- 旧capture：保留的 `analysis/static_candidate_capture_v2/static_v2` 内 native7k 17视角。新旧checkpoint路径、字节数、mtime和四份元数据SHA相同；相机、视角、支持顺序、groups、seed0、16384预算、probe7100相同。不是重新比较不同训练前缀。
- 新记录38005条ID全部是旧记录的子集；相同ID的 current_world/current_normal/prior_normal/centers 数组逐元素相同，相机内参与外参也相同。唯一优化选项差异是新增 candidate_depth_source=spread。未重新计算全checkpoint SHA，不宣称这是逐字节模型文件对照。
- 已有评分入口在本地clean6de5c4419819f496fd88276ed539abe29f6835f1执行一次，退出0、17.298秒，462行JSON/CSV逐字段数值一致。与43e2ea0比较，score_capture/_summary/validate_record AST相同；未重写evaluator或门槛。
- GT SHA31547a31069f736792d4b13fff76c73483f59239dbbabe1971e115f9ab17171d与旧正式评价一致，继续使用原segments/annotations及单位。GT只用于本地离线score，不进入训练。没有重跑旧GT评分，也没有开始训练。

统计单位为候选—视角观测，不是独立高斯。所有gain=当前位置误差−候选位置误差，正数表示改善；最近三角面距离、参考第一命中z和法线各自有效域分别报告，不能混同正式CD、表面归属或ALR实际梯度收益。

## 主要结果：12个扩展视角的接受组

| 指标 | 原DA3候选 | 传播候选 |
|---|---:|---:|
| 接受观测数 | 47669 | 9115 |
| 最近表面距离平均改善(mm) | -7.963 | +25.260 |
| 最近表面距离改善比例 | 37.70% | 57.03% |
| 最近距离恶化超过5mm | 52.38% | 30.83% |
| 第一命中z平均改善(mm) | +16.442 | +57.501 |
| 第一命中z改善比例 | 43.79% | 61.13% |
| GT法线有效域中的法线改善比例 | 64.90% | 88.71% |
| 同一法线有效域中z与法线均改善 | 27.87% | 54.34% |

传播组第一命中z有效8936条、法线对照有效8287条；原DA3对应45694/35559条。最近距离以各自接受全域为分母，z以visible_count为分母，法线与联合四象限以normal_count为分母。没有把视角中位数平均成总体中位数。

传播组10/12视角最近距离均值为正，旧组4/12。新组按视角宏平均改善13.777mm、按观测加权25.260mm；两者均正，不能只用加权均值掩盖视角差异。原五问题视角也从平均恶化1.110mm转为改善16.282mm，改善比例43.12%→56.15%，接受数16210→1918。全17视角接受63879→11033，最近距离平均-6.224→+23.699mm。

目前结果足以说明“当前完整候选流程提出的已接受位置建议，比原流程有更好的静态质量分布”，不能说明每个高斯都变好。43%左右最近距离未改善，30.83%还恶化超过5mm，不应把57.03%称为真实几何正确率。

## 收益与覆盖必须同时解释

- 原采样总数278477不变；传播可用38005（13.65%），共同支持可比较23706，接受11033。扩展组接受数量减少80.88%，全17组减少82.73%。本轮是更窄的适用域，不能把质量提升和覆盖不变同时宣称成立。
- 11033条新接受中6747条旧流程也接受、3141条旧流程拒绝但可比较、1145条旧流程不可比较。这是ID计数对照；没有对这些交集另外访问GT或计算共同域误差，因此不能把新旧接受组的均值差当成同一批高斯的纯目标改进量。
- 原始 prior_normal 在共享ID上完全相同，因此法线改善率提升来自候选域/接受域组成变化，不是生成了更准确的DA3法线。位置目标改变和传播有效域过滤的独立贡献尚未分离。
- 新扩展组拒绝但可比较的候选，最近距离平均也改善12.226mm、改善比例52.32%；接受组为25.260mm、57.03%。NCC在此域仍有描述性富集，但差值不是随机因果效应，更不是位置替换有益的保证。

## 哪些区域还危险

按参考GT第一命中对象分组，不是Gaussian的真实归属；下表为新传播接受组在12扩展视角的记录。

|---|---:|---:|---:|---:|
| 69:wall | 2816 | +23.961 | 67.29% | 23.40% |
| 71:wall | 775 | +164.630 | 73.94% | 17.55% |
| 75:storage rack | 891 | +2.743 | 54.43% | 23.91% |
| 68:door | 308 | +34.917 | 70.78% | 21.75% |

| 63:cabinet | 205 | -15.763 | 28.29% | 65.85% |

71号墙贡献扩展组净最近距离改善总和约55.4%；描述性扣除该区域后其余8340条仍平均改善12.309mm，进一步扣除69号墙后其余5524条仍改善6.369mm。这只解释收益集中度，不是筛除区域后的新正式分数，不能用GT区域制定训练门控。

仍有两种明显反例：

1. 89号墙法线改善率99.49%，而位置改善仅21.90%，法线有效域约77.65%只有法线改善而z未改善。它继续支持位置与法线不能互相代证；并不证明下一步固定法线NCC一定能修复。
2. DSC06495、DSC06532接受目标最近距离均值分别恶化9.640/10.232mm，中位数分别恶化11.937/9.098mm。DSC06348均值改善34.552mm但中位数恶化1.201mm，只有47.81%改善；少量大收益可以使均值转正。不能把全局正均值说成所有视角都可靠。

柜体等区域的最近距离与第一命中z均值还可能方向不同，这两种代理对表面归属的敏感性不同；当前记录不足以确诊错误来自锚点偏差、跨面传播、NCC歧义或对应关系。不要据此把某一种原因写成已证明事实。

## 下一步建议与明确边界

建议与用户讨论：保持已批准v3_spread原样，从同一原生7K续训到30K，预算16384、early截止15000、原ALR/DA3深度loss/LR及TSDF/正式几何评价均不变，只检验该单一方法变化能否落实为重建收益。既有baseline/V1/early直接复用，不补baseline或新的诊断框架。

本次结果比之前rawDA3接受目标普遍负向更有理由投入一轮重建实验；但“最终mesh一定提升”“Tool Room创新已完成”“足够发表/泛化成立”都尚未得到支持。不要因为静态目标改善就省略正式Accuracy/Completeness/CD和1/2/5cm PRF，也不能把这里的25.260mm当最终mesh CD改善。

本轮不自动加入固定法线NCC、传播depthloss、步长缩小、学习率改变、GT区域过滤或扩大预算。它们会改变实验问题，需结果反馈后另行讨论。传播源每次active selector调用均执行，GPU训练成本可能高于既有early；没有实际30K耗时记录，不能沿用旧约1小时估计作保证，不另加profiling框架作为前置。
