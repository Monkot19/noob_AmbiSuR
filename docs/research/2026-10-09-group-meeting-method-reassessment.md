# 组会问题：A/S/N、五状态与优化动作的科学重审

日期：2026-10-09。性质：文献与理论研究备忘录，**不是批准设计的替换规格，也不授权代码、训练、GT 访问或恢复实验**。当前 Geometry Q 暂停与 Utility 冻结合同保持不变。

## 1. 当前应当承认的事实

原设计的工程闭包较完整，科学推导没有同样完整。公式有界、状态分支穷尽、梯度可以执行，分别只能证明数值形式、逻辑覆盖和工程可实现，不能证明误差预测、动作适用性或创新性。我此前把这些层面的完整性写得过于接近方法已经成立，需要纠正。

本项目冻结证据见 [soft-v4 失败解剖](2026-09-28-softcal-v4-g1-failure-anatomy.md)：Tool Room seed0、7000 步的 AUROC(N)=0.547598，AUROC(A)=0.545626，AUROC(1-S)=0.530889；组合相对最佳单项只增加 0.001972，正式 G1 失败。Consensus=0，Geometry-led=22/1,417,059。不能通过降低门槛、换评价域、延长训练或改名挽救原主张；状态为空的具体门原因尚未得到逐门与时间链定位。

同一冻结资产上，1-r_p 的边际 AUROC=0.623265；[A,1-S] 的空间 OOF AUROC 从 0.519882 到加入该信号后的 0.609023，差值 0.089141，固定 voxel-bootstrap 区间 [0.067379,0.108420]。这个结果支持局部条件预测信息；不支持独立场景泛化、正确先验识别或训练收益。Utility 首次 GT 访问已发生，六组测量计算后发布因 ndarray/list 聚合接口错误而 INCONCLUSIVE；其科学结论仍未知。本备忘录不读取这些 GT/实验资产，也不修复或重跑该评价。

## 2. AmbiSuR 的 A 有什么理论，没有什么理论

[AmbiSuR §3.3、附录 B/C](https://arxiv.org/html/2605.12494v1) 从 SH 正交性得到：非 DC 系数平方和与整球面上颜色偏离 DC 的积分能量相对应。这是视角相关颜色变化的数学依据。它不是几何误差的恒等式。正确镜面也可有高能量，错误低纹理平面也可有低能量。

其低端指示基于训练中的折中状态及实验观察：极低 SH 可能表示监督/优化不足或错误外观烘焙；不是从高端 Parseval 身份对称推出的结论。论文通过双端、局部 mask 与参数分离消融支持完整方法，不能将它概括为“两端 SH 都被理论证明错误”。

还需区分两个比较对象：官方 I_SH 的双端集合，与当前 Core 中只有高端的连续 A。未来若主张“比原方法找到更多错误高斯”，必须比较官方双端选择，不能只击败我们自己重定义的单端 A。比较应固定干预/选择预算或假阳性率，报告 precision、recall、PR 及空间稳定性；选择更多本身不构成增益。

### 2.1 观测条件为何可能改变 SH 的解释

以下是说明机制的简化推导，假设固定几何、线性 SH、已知噪声协方差、没有渲染 clamp 或饱和删失。记实际方向上的 SH 设计矩阵为 Y，颜色为 y=Y beta+epsilon，W=Cov(epsilon)^(-1)。可辨识时 GLS 系数协方差为 (Y^T W Y)^(-1)，于是无偏估计满足：

\[
\mathbb E\|\widehat\beta\|^2=\|\beta\|^2+\operatorname{tr}\operatorname{Cov}(\widehat\beta).
\]

所以，大系数可能来自真实视角外观，也可能含有估计不稳定；小系数可能来自真实漫反射，也可能来自欠拟合、正则化或低信噪比。实际神经/GS 优化并不满足上述全部假设，不能直接把此式变成新的减法分数。

该推导解释了“观测条件应参与解释 A”的动机：检查实际方向的设计矩阵是否有信息、噪声是否足够小；它没有推出旧 S，也没有推出 N。原 S 只描述几何覆盖，缺少图像纹理、暗部信噪比、饱和、合成贡献强度及外观补偿。很多视角观察同一片纯白墙，仍未必能精确定位深度。方向信息丰富与几何信息丰富也不等价。

## 3. N=1-S(1-A) 为什么不构成充分理论

设 U=1-S，则 N=A+U-AU。它是平滑 OR。若 A、U 分别是同一条件信息下两个事件的校准概率，且这两个事件条件独立，才可将其解释为并集概率。当前分位归一化的 A、计数/角度归一化的 S 不是这类概率；两者来自同一训练模型，独立性也没有依据。

更深的问题是，即使 N 能预测几何高误差，它也未必预测某个修复动作有效。需要分别定义：

1. 当前几何错误风险：一个固定几何误差事件。
2. 几何可辨识性：图像能否区分不同几何解。
3. 具体先验干预价值：使用该先验是否比不使用更好。

高光、暗部可能同时损害图像约束与基础模型先验；因此风险增加不能直接推出先验权重增加。特别是本项目已有的 1-r_p，语义上是先验警告量；低 r_p 不能加强先验监督。将它加入误差预测模型可以成立，将它未经验证加入需求增益公式则可能产生反向动作。

## 4. 更有解释力的统一理论目标

推荐研究的问题是：**在外观可以补偿几何扰动时，哪些几何自由度仍受到图像约束；哪种先验能够可靠补足剩余自由度？** 这是一个新研究假设，不是已验证新算法。

### 4.1 从颜色复杂度到外观补偿后的几何信息

局部线性化整个相关渲染残差：delta r ≈ J_g delta g + J_a delta a。其中 g 为目标几何自由度，a 为 nuisance 自由度，可包括 SH、曝光、opacity 及邻域可补偿参数。opacity 不是物理上纯外观参数；这里只按研究目标定义消元角色。相机固定或其不确定性如何处理必须另行声明。

在固定可见性/排序的局部、加权二次近似中，令 H=J^T W J。在 H_aa 可逆的可辨识 nuisance 子空间，消去允许优化的 a 后，几何有效曲率为：

\[
H_{\mathrm{eff}}=H_{gg}-H_{ga}H_{aa}^{-1}H_{ag}.
\]

奇异时必须明确可辨识子空间、广义逆或正则化合同。添加 lambda I 是加入正则化，不能把正则化提供的曲率当作图像证据。参数需要尺度规范化，旋转需要合法局部坐标。

H_eff 衡量几何变化在外观重新拟合后还留下多少不能消除的图像变化。小特征值对应弱约束方向。这比“几何梯度大”或“看见次数多”更接近原科学问题。[FisherRF](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/02130.pdf) 与 [PUP 3D-GS](https://openaccess.thecvf.com/content/CVPR2025/papers/Hanson_PUP_3D-GS_Principled_Uncertainty_Pruning_for_3D_Gaussian_Splatting_CVPR_2025_paper.pdf) 为敏感度/信息的应用提供相关基础；这里的 nuisance 消元是标准局部最小二乘分析，不能包装成我们的原创定理。

它也不是几何正确性证明：错误模型可被强约束到一个错误局部解；未建模反射可造成偏差；遮挡改变与拓扑变化使线性近似失效。完整百万高斯 Hessian 不可作为当前单卡可行性的承诺。若未来研究，应先限定小型空间单元与少量方向，比较近似和真实有限扰动，不先大规模开发通用系统，也不自动恢复已经暂停的 Geometry Q。

在该概率模型下，信息来自渲染 Jacobian 与噪声模型；训练损失梯度平方只是可能的近似。收敛时残差/梯度很小，渲染 Jacobian 仍可以很大，不能把“更新小”直接等同“信息少”。同样，当前可见性由当前几何决定，错表面的可见性支持也可能自我强化；评价这种证据需要明确其模型依赖。

### 4.2 理论上需求与先验可靠性如何共同决定使用程度

用一个标量例子说明，不把真实训练简化成该融合器。真实量为 z，内部估计 G=z+e_g，先验 P=z+e_p。令 R_g=E[e_g²]，R_p=E[e_p²]，C=E[e_g e_p]；这里包含偏差，不要求误差独立。融合为 z_hat=(1-w)G+wP，则：

\[
R(w)=(1-w)^2R_g+w^2R_p+2w(1-w)C.
\]

当 E[(e_g-e_p)²]=R_g+R_p-2C>0 时，限制在 [0,1] 的最小风险权重是：

\[
w^*=\operatorname{clip}_{[0,1]}\frac{R_g-C}{R_g+R_p-2C}.
\]

两者误差几乎完全相同时分母退化，不能据此制造高置信融合。DA3 已用于初始化/监督，使 C 不可忽视。未知风险必须保留未知，不把当前 r_p/r_g 直接代入这些量。

无偏独立时，它退化为 w*=v_g/(v_g+v_p)。若内部方差9、先验方差1，w*=0.9；若先验另有偏差10，R_p=101，w*=9/110≈0.0818。**相同内部欠约束，对先验的正确使用程度可能相差一个数量级。** 这给出了两种信息必须同时参与决策的理由，并没有推出五种离散状态。

多维真实参数还要求知道先验约束哪个方向：可靠法线不等于可靠深度，法线角度约束不直接提供平面绝对位置。优化一个方向与另一个方向可以需要不同监督。GT-free 估计这些风险和偏差仍是待解决问题，不能因写出风险最小化公式便声称已解决。

## 5. 五状态应该怎样重新审视

现有五状态是决策规则的五类标签，不是被观测发现的五类物理失效。规则可以穷尽，并不能证明五类是必要、最小或最优划分。

- 外部 T_p 来自两个分量的几何平均，内部 T_g 来自三个不同分量；同落 [0,1] 不意味着同单位/同误差概率。直接相减的 Delta 不具备已证明的选边语义。
- 两条来源相关且都可能有系统偏差。Consensus 是协议一致，不是几何正确；同一错误表面可跨视图自洽。
- 当前正式证据中 r_g 的高分并未表现出正确风险方向；后续语义审计没有找到实现修复理由。其当前身份仅为内部一致性 telemetry，不得用符号翻转恢复路由。
- 原设计 §7.3 中 Bypass 与 Geometry-led 的 C4 连续更新相同。生命周期才增加后续差异；不能声称现有五个标签已经对应五种必要的连续优化策略。
- Abstain 合并证据缺失、双方不可信、共同支持缺失与冲突无明显优势。它们可能需要不同证据收集方式；全冻结几何可能维持错误，如何拒绝哪些辅助项也需要说明。

可以保留离散标签用于日志和控制工程，但是否保留五个必须服从验证。若连续策略同样有效、若两个状态最优动作相同，或关键状态没有有效支持，应合并、简化或放弃“状态数”作为贡献。状态必要性需要状态×动作交互效应，不能只画状态热图。

## 7. 建议收敛到一条主假设，避免再堆模块

三种路线的取舍如下。

1. **推荐研究方向：几何可辨识性与先验适用性共同指导、针对方向的补偿。** 假设是：可靠先验只在图像无法约束的几何方向上值得介入；外观异常与几何风险需要区分；观测/先验均不足时不扩增错误。它可以解释检测、路由与拓扑的联系，但目前尚未验证，不能宣布是可发表方案。
2. **低成本过渡：固定先验风险证据的复核与简单连续门控研究。** 优先完成已有冻结 Utility 结论的合法接口恢复，恢复仍需单独明确授权；然后决定是否值得研究最小干预。该路线利用现有资产，但单纯 confidence 权重创新空间有限，不能代替推荐方向的机制验证。
3. **结构线索路线：按 IndoorGS 引入可信线/平面来源。** 机制清楚但增加预处理、来源追踪、结构假设，偏离当前高反射压力测试与最小 Core 范围。只有现有约束信息确实不足、研究问题需要这些结构输入时再考虑，不同时启动两条大工程线。

推荐方向里的下表只是可检验的动作假设，不是新增状态定义，也不要求恰好四类；一处可以同时满足多个机制。

| 待诊断机制 | 需要的证据 | 可检验的动作差异 | 应避免的误用 |
|---|---|---|---|
| 观测不足且先验在某方向可用 | 有效几何信息弱，先验该方向的支持有效 | 对该方向有界补偿；改善前限制复制 | 先验 confidence 高就全参数拉向先验 |
| 视角外观变化主要由正确表面支持 | 去掉异常视图后仍有几何支持；跨视图/扰动证据未指向错误 | 几何优先使用有效视图；保留外观解释，抑制因 RGB 残差驱动的无依据增密 | 高 SH 一律平滑、冻结或认定几何错误 |
| 先验压平真实边缘/细节 | 边缘有图像/结构支持；先验偏差可定位，法线/深度支持分开 | 拒绝有害先验分量；在可信表面方向维护细节 | 先验与内部冲突就相信内部，或不加验证复制 |
| 两路均不能确定 | 显式支持缺失或候选解释无法区分 | 保护、延后、限制不可逆拓扑；寻求已有训练视图的有效支持 | 当成最大错误自动删除，或永远冻结所有基础几何 |

针对视图与方向的处理尚需未来单独修订 Core 合同；不能混入现有 C0-C6，不能偷渡 Supporting 曝光、Ray loss、截断或完整 BRDF。

## 8. 证明链应该怎样补齐

最小研究顺序是“机理辨识 → 特定动作 → 独立验证”，不先开发完整状态机或全套新评价核心。

### 8.1 机理辨识

预注册少量合成对照，分别控制方向覆盖、纹理/信噪比、视角反射与几何偏移，并加入可靠先验和系统偏差先验。需特别包含：正确高 SH 表面、错误低 SH 平面、双路一致但同时错误、暗部且先验错误。一次改变一个因素，检查 A、S、内部一致性与未来候选究竟响应哪个机制。

合成材料或程序生成的标签可用于已知机制验证；真实数据不制作人工高光 mask。高斯中心离 GT 表面只测位置偏离，不能覆盖法线错误、细节缺失或 mesh completeness，不能用它认证所有优化/拓扑动作。旧 G1 决策保持不变；新增指标若需要，应在新合同中明确并与官方最终评价协议分工。

### 8.2 特定动作验证

从同一模型与 optimizer/RNG 状态分支，使用同一视图序列比较一个有界动作与不执行该动作。由于 alpha blending 与优化器使高斯互相耦合，作用单元宜为预注册空间单元，报告邻域外溢，不能把全场景分支差冒充每个高斯独立因果收益。

关键证据是交互：同一个动作在机制甲有效、机制乙有害；机制甲应当使用的动作优于全体通用加权。需要比较连续门控、保留/合并状态，以及控制选择数量和梯度预算的对照。若五状态不能超过更简单控制策略，应删去状态贡献主张。

降低训练 RGB 或虚拟 held-out photometric loss 只能作为代理；反射歧义下不代表几何变好。最终仍要同时看对应几何量、mesh 完整性、外观保护与资源代价。GT 只用于单独离线评价，不能形成部署 gate 或进入缓存/checkpoint。

### 8.3 独立确认与停止条件

复用冻结统计、生产 serializer、空间分折和发布链。只为新增数据/接口合同补测试；不得为每个场景复制核心。Utility 已触碰 GT，未来新方案不再把它称作未触碰确认场景；其结果不得回流已暂停 Geometry 候选选择。新假设需要另行设计独立确认，且包含多 seed。

如果机理信号不能区分正确反射与错误几何，不扩展动作；如果动作只有普遍加权效果，不声称状态必要；如果状态×动作交互不成立，简化策略；如果跨场景不成立，收缩主张。高阶理论与小型实验都不自动保证新颖性或投稿等级。

## 9. 可给导师的答复

> 老师指出的三处缺口成立：原 N 的理论只停留在覆盖与 SH 异常的直觉，五状态没有从失效机制或动作风险推出，不同状态的动作收益也没有得到验证。正式负结果已经否定固定 N 的预测效度，不能再靠调门槛维护它。我们会区分 SH 的视角颜色能量、观测对几何自由度的约束、以及先验干预的实际价值。新的研究问题是：允许外观补偿以后，哪些几何方向仍欠约束，先验是否能可靠补足；由此决定干预方向和是否限制错误扩增。状态数量服从机制与动作交互验证，不预设必须五个。下一步先做有限的机制与单动作对照，再考虑路由和生命周期；现有 1-r_p 结果仅保留为预测证据，不当作训练改进证明。
