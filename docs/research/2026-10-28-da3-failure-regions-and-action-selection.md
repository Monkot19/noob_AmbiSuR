# DA3 区域误差、选择集合与下一步研究决策

## 1. 阶段状态与数据集

实现、首版30K验证及探索性误差分析可以记为阶段完成；不能据现有单场景单seed与恢复混杂宣布模块定型或稳定有效。2.34% 是进入小规模迁移筛查的理由，不是必须先超过某百分比才有资格迁移。Utility 是检验适用范围的一部分，不是奖励足够大 Tool Room 提升后的附加任务。

本轮发现了具体的先验位置/法线差异，因此可以先做一次针对实际候选的核查，再选择一项改动；不建议无限在 Tool Room GT 上搜索门槛后才去 Utility。若继续修改，保留 early 作为已冻结对照。

Tool Room/Utility Room 可作为 ScanNet++ 室内压力测试，不存在方法研究必须与 baseline 完全相同数据集的规则。[ScanNet++ 官方数据与代码](https://github.com/scannetpp/scannetpp)提供配准图像、扫描几何和深度渲染流程，[官方 NVS 说明](https://scannetpp.mlsg.cit.tum.de/scannetpp/benchmark/nvs)规定图像任务协议。我们自定的全表面 mesh 协议不能冒称官方 ScanNet++ 表面排行榜；DTU/TnT 官方协议仍用于主流表面重建可比性。[In Depth We Trust §5.1](https://arxiv.org/html/2604.05715v1)也使用 ScanNet++ 与 GT 深度评价，说明在 GS 先验研究中使用它有直接先例，不能说明我们这两场景的具体设置天然正确。新视角结论需固定测试划分；当前全部视角训练下的五视角PSNR不支持该结论。

## 3. 位置和法线的理论区别

实际生产法线来自反投影点的邻域差分叉积。记 `p(u)=D(u)K^-1 u`，当局部所有有效深度统一变为 `D'(u)=aD(u), a>0`，两条差分各乘a，叉积乘a²，经归一化法线不变，而位置与metric深度均变。数值平面测试实际调用生产函数验证。对相机外参固定、正尺度、非退化邻域成立；不意味着任意深度偏差都不影响法线，也不证明所有DA3法线可靠。

因此“可以接受先验法线”与“可以把中心直接移动到先验绝对位置”是不同命题。ALR可通过深度影响位置，但纯法线信息不能确定统一尺度/平行平面位置。已有baseline软深度监督与V2硬位置替换也不是同一干预，不能因baseline已用DA3就假设二者风险相同。

## 4. 当前 A、E、R 与用户提出的独立选择

实际代码：

- A：原SH双端筛选。
- E：只从 `~A` 池抽样，先验候选通过NCC比较的高斯；`A∩E=∅`由代码定义，并非自然互补性的证据。
- ALR标签：`A∪E`，再复用原标签渲染和soft像素mask。
- 实际被移动集合记作M：重定位轮次`M=E`，其他轮次M为空；early7100..14900每100轮执行，15000后M为空但E补选/ALR继续。集合指当轮当参考视角，不是全训练永久标签。

所以“给重定位选中的高斯也加ALR”已经实现。若用户想让原A与重定位独立找高斯，可将新的位置候选集合记作R：让R不再排除A，允许`A∩R`，然后ALR覆盖`A∪R`。在执行重定位的轮次，行动关系：A∩R两者；A\R仅ALR；R\A重定位并ALR；两者之外维持原训练。这里只解释集合关系，不引入新四状态框架，也不宣称soft渲染mask是精确逐参数隔离。

还需明确选择频率：若R仍每个活跃训练轮次刷新，只限制实际移动M的时序，才保留现有E的ALR补选频率；若R只每100轮选择，其他轮次回到仅A监督，则额外改变了ALR频率。不能把两种方案当成同一个单变量改动，也不能把15K后停止重定位说成停止所有补选。

A衡量SH异常风险/外观歧义，R衡量具体位置替代在某代理下是否值得尝试，二者没有集合包含的理论保证；两者交集可能值得看，但不能无实验就强制扩大R。尤其联合位置+法线NCC胜利，不能分别证明新位置更准、新法线更准或二者动作都该执行。把R全部自动加入ALR也只是待检验策略，并非联合候选获胜的逻辑必然结论。

## 5. 可借鉴方法与应针对的原因

已重新读实际固定源码，不仅README：

1. [DP-GS 原文](https://arxiv.org/html/2607.03765v1)与[train.py300..335](https://github.com/hanl2010/DP-GS/blob/dc1ce835ea3c6bb7887333c50df7a13497a45c09/train.py#L300)：用逐像素NCC confidence选择当前渲染深度锚点，经normal关系传播，并用normal边缘限制传播。不是直接信任所有外部metric深度。在同一相机、同一局部平面，`nᵀ(d_i r_i)=nᵀ(d_j r_j)`，故`d_i=(nᵀr_j)/(nᵀr_i) d_j`，分母非零、局部表面关系成立且锚点可信才可用。若真实候选审计显示“法线结构可用、绝对位置偏”，可研究从可靠位置锚点和DA3法线生成候选位置，替换当前raw DA3目标；不能现在就宣布有效或跨物体传播。
2. [VCR-GauS 原文](https://arxiv.org/abs/2406.05774)与固定[trainer.py266..279](https://github.com/HLinChen/VCR-GauS/blob/aa715d19bfacfa9d491f477c572eab1839dcee3e/trainer.py#L266)、[cos_weight](https://github.com/HLinChen/VCR-GauS/blob/aa715d19bfacfa9d491f477c572eab1839dcee3e/tools/loss_utils.py#L135)：对detach直接法线与先验法线的余弦形成指数权重，再监督深度导出法线。若真实候选的normal监督造成损伤，这是兼容现有ALR的低改动候选；一致不代表正确，也可能压低大角度纠错，不自动选用。
3. [Confidence matters](https://arxiv.org/html/2608.06117v1)：官方train在上一轮已读、固定源码已归档。先验confidence和阶段加权有实证基础，但本次高置信仍常劣于当前几何，因此单加confidence不能被当作已证明足够的修复或独立创新。
4. [In Depth We Trust §4–5](https://arxiv.org/html/2604.05715v1)：区分绝对深度校正与对齐后的相对梯度监督，并在ScanNet++验证。未定位到可核验官方代码，当前只作为论文问题分解与数据使用先例，不称已读源码或可直接移植。

第一版分析目录保留DP-GS train、VCR trainer/loss_utils及固定commit/源URL/SHA清单；未安装或运行这些供体。

## 6. 建议的最小下一步（讨论稿）

不同时扩大候选池、改变目标来源、改ALR、调学习率。先利用现有7K或已有模型，在实际原生renderer上离线重放少量参考视角的真实候选比较，不优化、不训练，只输出原位置/获胜目标到GT的误差变化、先验法线误差及A/补选集合。它直接检验“实际选择函数接受的目标有metric偏差”的假设；当前五视角像素审计不能代替它。本地缺少训练原生扩展，尚未执行该重放，不将TSDF视角探针冒充训练选择。静态7K模型上的重放是该快照处的反事实候选检查，不是恢复原实验7100或更晚的历史轨迹，也不能单独证明已发生损伤的历史因果。

若候选目标确实常比原位置差、法线相对可用，优先讨论一版DP-GS式锚点化候选位置适配，保留原A/ALR/预算/窗口，避免同时修改多个因素。若位置正确而normal差，才优先讨论ALR监督质量；若目标和法线均好而最终退化，再查执行/后续拓扑。任何分支都不能保证形成创新；贡献需来自可解释且稳定的新增能力。

一次有明确假设的修改之后应冻结配置做Utility迁移筛查；Utility若再参与调参，应如实作为开发场景，另留确认场景。正式因果与论文主张仍需同恢复关闭模块对照、重复性和官方基准证据，不在本轮自动补跑。
