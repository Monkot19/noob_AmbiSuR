# 实验清单目录

这里保存每一次实际提交到 AutoDL 的实验清单。不要直接修改
`docs/research/experiment-manifest-template.md`；每次实验先复制模板，再填写为一份独立记录。

推荐命名：

```text
YYYYMMDD_<scene>_<stage>_<commit8>_seed<seed>.md
```

例如：

```text
20260908_d415cc449b_Tool_Room_C2_a1b2c3d4_seed0.md
```

一份清单只对应一个确定的代码提交、一个场景、一个随机种子和一条训练命令。
若因中断而重跑，创建新清单并增加 `_retry1`，不要覆盖旧记录。

实验开始前至少填写：

- Git 提交 SHA、标签和工作区是否干净；
- 数据集路径与场景；
- 随机种子、完整命令和解析后的配置；
- 当前阶段相对上一阶段唯一允许变化的内容；
- 预期输出目录。

实验结束后至少补齐：

- 成功、失败或中止状态；
- 指标、耗时、峰值显存；
- 输出文件校验值或文件清单；
- 异常、偏离预案和是否允许进入下一阶段；
- 对应本地分析报告的位置。

实验产物本身不建议提交进 Git。Git 中保存清单、配置、脚本和小型指标表；大体积 checkpoint、点云、mesh、渲染图和日志放在项目外的结果归档目录，并在清单中写明绝对路径。
